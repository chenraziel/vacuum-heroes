# VACUUM HEROES – Full Game Design Document v1.0

## 1. Vision
Hyper-casual cleaning game with light mid-core depth.  
Player = cleaning hero. Goal: #1 cleaning game worldwide in 12 months.  
Tone: fun, clean, energetic, not too childish.  
Languages at launch: Hebrew + English.

## 2. Core Loop
Enter Level → Swipe move vacuum → Hold Turbo → Clean dirt + Collect gems → Combo → Finish before timer → Stars + Coins → Upgrade/Shop/Multiplayer → Repeat

**Target session:** 2–4 minutes

## 3. Controls
- Drag/Swipe = move
- Hold = Turbo Suction
- Tap = power-ups / UI
- Portrait only

## 4. Economy
| Currency | Use | Source |
|----------|-----|--------|
| Coins (soft) | upgrades, temp power-ups, basic skins | wins, daily, achievements |
| Gems (hard) | energy fill, premium skins, skip | IAP, Battle Pass, rare events |
| Energy | enter level (cost 10) | regen 1 / 6 min, max 100 |

**Rule: No Pay-to-Win.** Money = convenience + cosmetics only.

## 5. Levels
8 Chapters × 8+ levels: Kitchen, Living Room, Office, Beach, Patio, Mall, Airport, Space Station.  
3 stars per level. Boss at end of each chapter.

## 6. Multiplayer (v1.0)
Async only: Challenge Friend + Leaderboards.  
Real-time → Season 2.

## 7. Monetization
VIP Monthly, Battle Pass (6–8 weeks), 4 packs + gems, Rewarded ads only, First-time Starter Pack.

## 8. LiveOps
Weekly event, Season every 6–8 weeks, 7-day daily rewards, limited skins.

## 9. Technical
Engine: Godot 4 | iOS 14+ / Android 8+ | Portrait | Offline + Cloud Save  
Analytics: Firebase + GameAnalytics | Attribution: Adjust/AppsFlyer

## 10. Soft Launch KPIs
D1 40%+ | D7 15%+ | Crash-free 99.5%+ | Paying 2.5%+ | ARPDAU $0.08+ | Battle Pass attach 12%+

## Win / Fail
Win: 100% clean before time → 1–3 stars  
Fail: time up / energy 0
