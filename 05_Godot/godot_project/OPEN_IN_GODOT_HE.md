# איך לפתוח את הפרויקט ב-Godot

1. הורד Godot 4.3+ (Standard)
2. Godot → **Import** → בחר את התיקייה `godot_project` (שבה יש `project.godot`)
3. או: Clone את הריפו → `05_Godot/godot_project`
4. לחץ **Play (F5)** – אמורה להיפתח TestArena
5. **גרור** את הריבוע הסגול, **גע בחום** (dirt) ובצבעוני (gems)

## אם יש error
- ודא Godot 4.3+
- Project → Project Settings → Autoload: Economy + GameManager
- שלח screenshot ל-CEO
